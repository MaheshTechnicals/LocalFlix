# Code of Conduct

LocalFlix is a small, friendly project. We want everyone who uses it, reports a bug or sends a pull request to feel welcome, whatever their experience, background or the language they write in.

## Expected behaviour

- Be patient and kind, especially with newcomers and with people writing in a second language.
- Assume good intent. Ask before concluding.
- Keep feedback about the work, not the person. Be specific and constructive.
- Respect people's time: search existing issues first, and give enough detail to reproduce a problem.

## Not acceptable

- Harassment, insults, or personal or political attacks.
- Discriminatory language or imagery of any kind.
- Publishing someone's private information without permission.
- Sustained off-topic disruption, spam or self-promotion.
- Requests for help pirating content. LocalFlix plays your own files; questions about obtaining copyrighted media will be closed.

## Scope

This applies in issues, pull requests, discussions and any other project space, and when someone represents the project elsewhere.

## Enforcement

Report problems privately to the maintainer through GitHub (the **Report content** option on any comment, or a private security advisory for anything sensitive). Reports are handled confidentially. The maintainer may edit or remove content, or temporarily or permanently block people who break these guidelines.

This document is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
